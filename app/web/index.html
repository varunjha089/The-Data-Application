Project

Python environment

checking

The scripts run in a virtual environment (venv), so nothing is installed into your system Python. One shared venv serves every project; it is kept in the application's settings folder, not in a project, so deleting a project never removes it.

Years in the plots

The years that the plots over time draw, for the whole project. The tables always keep every year. A sheet can still choose all years or its own range (on its page, under Your choices).

Look of the plots

For every plot of this project. Generate a plot again to see the change. Only the picture changes, never the data.

0 = all rows (at most 1000). Every table is also saved as a PNG and an SVG picture (the CSV always has every row); a table picture can have its own number, set above it on its sheet's page.

AI writing (for all projects)

The Report page can ask an AI model to write the analysis of every figure and table. The model is sent only the summary tables of the sheets (their first rows), the notes of the scripts and, if you tick it below, the plot pictures; never your export. The provider charges you for its use.

Where do I get a key?

Main data

none

Choose the Scopus export (CSV). A copy is kept in the project's data/raw folder; your original file is never changed.

Report

Writes the results chapter of your report as LaTeX, in the project's folder Report: one file per figure and table, so you can drop one by deleting its file. Each gets three paragraphs: what the plot or table is and its limits (the application's own text), the analysis of your numbers and a short conclusion (written by the AI model). Your edits are kept: a file you changed or deleted is never written again.
